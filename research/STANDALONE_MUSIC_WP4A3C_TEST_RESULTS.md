# Tests and builds

Relevant host CTest: 12 groups pass, covering maintenance primitives, watchdog probe/coordinator, role/listener topology, new executable proof and generation receipts, internal atomic copies, legacy/Music file rollback/recovery and TinySC. Final focused generation follow-up also passes after adding bounds/missing rollback/interruption coverage. ASan/UBSan: six relevant groups pass. No full unrelated Base/proxy test rerun is claimed; no Base audio implementation changed in this phase.

Thirteen executable-proof cases cover live access, distinct readlink/open/read failure, wrong SHA/size, parent/start mismatch (modeling stale PID reuse), unknown role, atomic rename, unlink, process exit during a held proof, modeled UnionFS correlation failure, modeled copy-up inode mismatch, active copy/remove refusal and write-once generation artifacts. A PID reuse was modeled by a wrong expected start time; actual kernel PID reuse was not forced. Linux host rename/unlink tests retain direct live descriptor correlation; they do not claim to reproduce the old UnionFS internals.

Generation format tests cover valid expected paths, duplicate output refusal, missing/corrupted artifacts or receipts, stale source/wrong generation, tampered path metadata, rollback hash/corruption/missing artifacts, and interrupted new generation preserving the previous generation. All bundles stay unqualified. Existing tests retain watchdog failure, expired/foreign registration, duplicate listener, UI challenge failure, bounded recovery and refusal behavior. Added topology cases verify a genuine versioned session with its children and refusal of mixed generations.

Baby ARMv5 and Fab4 ARMv6 maintenance binaries compile static with GCC 8.4.0, -Os, soft float, 64-bit file offsets and -Werror. readelf finds no interpreter/dynamic dependency. Production binaries contain no SB_TEST overrides. QEMU production helpers read a private 20-slot semaphore set without changing it and refuse mutation on the non-Fab4 host. QEMU does not emulate UnionFS or prove actual target replacement safety.

Actual Fab4 used a hash-verified production ARM helper, not a host test build. It positively verifies proxy/web live contents and mappings and accurately refuses Base at open/ENOENT. The exact executed ELF is preserved under used-on-device; final local builds also contain the subsequently added host-tested pre-stage active-target command and generation topology guard. No final/local build is claimed installed on the device.

Limitations: no target replacement/whiteout experiment, no LEVEL 2 qualification, no physical coordinator launch or startup measurement, no device generation deployment or audio. The full static helper/receipt stack is not declared production-ready merely because software fixtures pass.
